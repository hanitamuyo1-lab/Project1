Works with Gmail, Outlook & Yahoo. Use an app password, not your real password — it's sent once to fetch your inbox and is never stored.

Gmail
  1. Go to Google Account → Security and turn on 2-Step Verification if it's off.
  2. Open myaccount.google.com/apppasswords.
  3. Name it anything (e.g. "Signal") and click Create.
  4. Copy the 16-character code Google shows you using the copy button — don't retype it by hand.
  5. Paste it into the App password field above. If your browser autofills something else in that field, clear it and paste again.

Outlook: Microsoft app passwords guide. Yahoo: Yahoo app passwords guide.
